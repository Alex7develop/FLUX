# Product vision

FLUX is not an AirDrop clone. Transfer is how people arrive. The product is what happens after something arrives.

Users should never decide a folder, an app, or a destination first. They drop a screenshot, a receipt, a card, a URL, a file. FLUX classifies, extracts, connects, and later retrieves it.

Long-term composition:

```text
AirDrop
+ Universal Clipboard
+ AI Scanner
+ Universal Inbox
+ Semantic Search
+ Knowledge Graph
```

Phase 0/1 only asks: does the empty state feel intelligent, calm, and expensive? If the shell is generic, later AI will not save the product.

The long-form brief is in `/FLUX_README.md`.
